Privacy policy

Theo streams is a personal tool used only by its owner. With the owner's permission it uses the YouTube Data API to create one private playlist on the owner's YouTube account and to add and remove videos in it.

It reads nothing else from the account. It keeps no personal data except its sign-in key, which is stored as an encrypted GitHub Actions secret, and a list of the videos it has added. Nothing is shared with anyone.

Access can be removed at any time at myaccount.google.com/permissions.
